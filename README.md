# Тон + каталог Jamendo

Сайт из одного файла `index.html`, без сборки. Музыку берёт из Jamendo — это легальный каталог независимых артистов (сотни тысяч треков).

## 1. Получите ключ
1. Зарегистрируйтесь на https://devportal.jamendo.com
2. Создайте приложение и скопируйте `client_id`.

## 2. Вставьте ключ
Откройте `index.html` и впишите ключ в строку `const CLIENT_ID = "";`.
Если оставить пустым, сайт сам попросит ключ при первом запуске и запомнит его в браузере.

## 3. Выложите в интернет (бесплатно)
- **Netlify Drop**: откройте https://app.netlify.com/drop и перетащите папку `ton-jamendo`.
- **Vercel**: `npx vercel` в папке проекта.
- **GitHub Pages**: загрузите файл в репозиторий и включите Pages в настройках.

## Важно
- Ключ виден в коде страницы. Для личного проекта это нормально; для публичного ограничьте ключ по домену в кабинете Jamendo.
- Бесплатный ключ предназначен для некоммерческого использования. Для рекламы и подписок нужна лицензия Jamendo.
- Если браузер блокирует запросы к API (ошибка CORS), нужен маленький прокси-сервер (например, функция Netlify).

## Spotify (полные треки)
1. Создайте приложение на https://developer.spotify.com/dashboard и скопируйте `Client ID`.
2. В настройках приложения добавьте Redirect URI — адрес вашего сайта (точно как в адресной строке, например `https://user.github.io/music/`).
3. Откройте вкладку «Spotify», нажмите «Войти» и вставьте Client ID. Нужен аккаунт **Premium**.
Вход идёт через PKCE, секретный ключ не требуется; токены хранятся только в браузере.

## YouTube (полные треки без Premium)
1. https://console.cloud.google.com → создайте проект → включите **YouTube Data API v3** → Credentials → Create API key.
2. Откройте вкладку «▶ YouTube», нажмите «Добавить ключ» и вставьте его (рекомендуется ограничить ключ по домену сайта).
Музыка играет через официальный встроенный плеер YouTube (видео в углу экрана). Бесплатная квота — около 100 поисков в сутки; результаты кэшируются на 12 часов.
Если ключ добавлен, вкладки «Татар-Башкир», «Шансон» и «Цой» тоже подмешивают полные треки из YouTube.

## Установка на Android
Сайт — это PWA, ставится как обычное приложение (иконка на экране, полноэкранный режим, работа в фоне):
1. Выложите сайт по **https** (например, GitHub Pages — см. выше).
2. Откройте адрес в **Chrome** на телефоне → появится плашка «Установить приложение» (или меню ⋮ → «Установить приложение» / «Добавить на главный экран»).

Нужен настоящий APK (например, для RuStore или раздачи файлом): откройте https://www.pwabuilder.com, вставьте адрес сайта и выберите Android → Download. Подпись и сборку сервис делает сам.
